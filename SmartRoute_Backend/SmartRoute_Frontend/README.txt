# SmartRoute Frontend Starter

This is the first frontend prototype for Karachi SmartRoute.

## Files
- `index.html` — dashboard structure
- `styles.css` — responsive dark dashboard styling
- `app.js` — location dropdowns, swap action and basic form validation

## Run
Open `index.html` in a browser.

## Important
This is currently a frontend-only prototype. It does not yet call the C backend, calculate routes, display live traffic, or use a live map. Those functions will be connected to the existing C17 program in the integration phase.

The map panel is a schematic illustration of the predefined network, not a live geographic map.
